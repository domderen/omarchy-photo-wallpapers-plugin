display contains a complete real Omarchy capture from the application. Open an
image for full size; original screens are linked below each pair. The native
panel uses a signed-out demo profile with synthetic sources and a one-hour
interval. Native panels were refreshed for 0.5.0 on 1 November. The selected
hero and varied app layouts retain the 30 October campaign. See [provenance](../assets/promo/PROVENANCE.md).
